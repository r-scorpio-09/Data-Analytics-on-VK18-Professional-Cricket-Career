**#VK18-Professional-Cricket-Career-Analysis**
A Python-based exploratory data analysis (EDA) project visualizing the career statistics, goals, and club appearances of Cristiano Ronaldo.

## Overview
This repository contains a Python-based Exploratory Data Analysis (EDA) on the career of Virat Kohli. It uses data visualizations to break down his runs, centuries, and performance across different cricket formats (Test, ODI, T20I) and teams like India and Royal Challengers Bengaluru.

## Visualizations Included
* **Format-wise Runs Analysis:** Pie charts and bar graphs showing total runs and centuries scored in Tests, ODIs, and T20Is.
* **Career Progression:** Tracking batting performance, strike rates, and statistics over the years.

## Technologies Used
* **Python** 3.x
* **Pandas** (Data Manipulation)
* **NumPy** (Numerical Computations)
* **Matplotlib** (Data Visualization)

## How to View
Since the data arrays are built directly into the code, no external datasets are required. Simply click on the `VK18.ipynb` file in the repository to view the Jupyter Notebook directly in your browser with all the charts and code output rendered.
